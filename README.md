# برنامج مطابقة وتعديل الأسماء العربية (Excel Name Matcher)

تطبيق سطح مكتب مستقل لنظام Windows مصمم لمقارنة قوائم الأسماء العربية من ملفات Excel مقابل شيت رئيسي ضخم (~30,000 سجل) بسرعة فائقة مع توحيد القواعد اللغوية والإملائية وتصدير النتائج بتنسيق RTL.

---

## 🌟 المميزات الرئيسية
1. **فهرسة سريعة بالاسم الأول (Bucket Indexing):** تتيح معالجة عشرات الآلاف من الأسماء بثوانٍ معدودة.
2. **قواعد توحيد الأسماء العربية الصارمة:**
   - توحيد الهمزات والألفات (`أ`، `إ`، `آ` -> `ا`).
   - توحيد التاء المربوطة (`ة` -> `ه`).
   - تحويل `ي` في نهاية الكلمات -> `ى`.
   - **فصل جميع الأسماء المركبة بمسافة:** (`عبد الله`، `عبد الرحمن`، `ابو بكر` بدون همزة، `صلاح الدين`، `عطا الله`).
3. **تخزين محلي محمول (Portable Cache):** حفظ الشيت الرئيسي محلياً بجانب البرنامج مرة واحدة دون الحاجة لإعادة اختياره عند كل تشغيل.
4. **تصدير منظم بـ 3 أعمدة فقط:**
   - `الاسم`: الاسم من الملف المدخل.
   - `الاسم المعدل`: الاسم المطابق.
   - `نسبة التطابق (%)`: تلوين الصفوف الأقل من 85% باللون الأصفر لتسهيل المراجعة.
5. **خيار شكل كتابة الاسم المعدل:** (مطابق للشيت الرئيسي OR مطبق عليه قواعد التوحيد).
6. **واجهة عصرية:** شريط تقدم وتحديثات غير قابلة للتجمد بفضل العمل في خيط خلفي (`Threading`).

---

## 🚀 التشغيل المباشر عبر Python

1. تثبيت المتطلبات:
   ```bash
   pip install -r requirements.txt
   ```
2. تشغيل البرنامج:
   ```bash
   python app.py
   ```

---

## 📦 بناء الملف التنفيذي (.exe)
قم بتشغيل الملف:
```cmd
build_exe.bat
```
أو عبر الأمر المباشر:
```bash
pyinstaller --noconfirm --onedir --windowed --name "ArabicNameMatcher" app.py
```
ستجد الملف التنفيذي جاهزاً للتشغيل في المجلد: `dist/ArabicNameMatcher/ArabicNameMatcher.exe`.
